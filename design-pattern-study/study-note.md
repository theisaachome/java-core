## Builder Pattern

Implement a Builder pattern.

we start by creating a Builder interface.
- identify the parts of the product and provide method to create those parts.
- it should provide a method to "assemble" or build the product/object.
- it must provide a way/method to get fully built object out. Optionally builder can keep reference to the product it has built so the same can be returned again in the future.

A director can be a separate class or client can play the role of director.
