## 1. Core Concepts Overview

### A. Classes and Objects
- **Class**: A custom data type acting as a blueprint for objects. Defines **State** (fields) and **Behavior** (methods).
- **Object**: An instance created from a class blueprint in memory.
- **Encapsulation**: Hiding internal implementation details using `private` visibility and controlling access through getter/setter methods.

```java
public class BankAccount {
    // State (Fields) - Keep private!
    private String accountHolder;
    private double balance;

    // Behavior (Methods)
    public void deposit(double amount) {
        if (amount > 0) {
            this.balance += amount;
        }
    }

    public double getBalance() {
        return balance;
    }
}
```

---

### B. Constructors
- Special methods executed during object instantiation.
- Share the **exact name** of the class with **no return type** (not even `void`).
- **Constructor Chaining (`this(...)`)**: Used to call another constructor within the same class to reduce duplicated initialization logic.

```java
public class User {
    private String username;
    private String email;

    // Primary Constructor
    public User(String username, String email) {
        this.username = username;
        this.email = email;
    }

    // Secondary Constructor (Chains to primary)
    public User(String username) {
        this(username, "unknown@example.com"); 
    }
}
```

---

### C. Initialization Blocks
1. **Instance Initialization Block**: Executes every time an instance is created, immediately *before* the constructor body.
2. **Static Initialization Block**: Executes **once** when the class is first loaded into memory by the JVM.

```java
public class Config {
    public static final Map<String, String> SETTINGS = new HashMap<>();

    // Static Block - runs once when class is loaded
    static {
        SETTINGS.put("ENV", "PRODUCTION");
        SETTINGS.put("VERSION", "1.0.0");
    }

    // Instance Block - runs before every constructor execution
    {
        System.out.println("New instance being instantiated...");
    }
}
```

## 2. Complete Code Example: `Money` Class

```java
import java.util.Currency;
import java.util.Objects;

public class Money {
    // Static initialization block
    static {
        System.out.println("[System Log] Money class loaded into JVM.");
    }

    private final long amountInCents; // Stores monetary amounts without rounding errors
    private final Currency currency;

    // Instance initialization block
    {
        // Executes prior to constructor body execution
    }

    // Primary Constructor
    public Money(long amountInCents, Currency currency) {
        if (amountInCents < 0) {
            throw new IllegalArgumentException("Amount cannot be negative");
        }
        this.currency = Objects.requireNonNull(currency, "Currency cannot be null");
        this.amountInCents = amountInCents;
    }

    // Secondary / Convenience Constructor (Defaults to USD)
    public Money(long amountInCents) {
        this(amountInCents, Currency.getInstance("USD"));
    }

    // Operations
    public Money add(Money other) {
        validateSameCurrency(other);
        return new Money(this.amountInCents + other.amountInCents, this.currency);
    }

    public Money subtract(Money other) {
        validateSameCurrency(other);
        return new Money(this.amountInCents - other.amountInCents, this.currency);
    }

    private void validateSameCurrency(Money other) {
        if (!this.currency.equals(other.currency)) {
            throw new IllegalArgumentException(
                "Cannot perform operation on different currencies: " +
                this.currency + " vs " + other.currency
            );
        }
    }

    // Getters
    public double getAmountInMajorUnits() {
        return amountInCents / 100.0;
    }

    public Currency getCurrency() {
        return currency;
    }

    @Override
    public String toString() {
        return String.format("%s %.2f", currency.getSymbol(), getAmountInMajorUnits());
    }

    public static void main(String[] args) {
        Money wallet = new Money(1500); // $15.00 USD
        Money paycheck = new Money(5025, Currency.getInstance("USD")); // $50.25 USD

        System.out.println("Wallet balance: " + wallet);
        System.out.println("Paycheck amount: " + paycheck);

        Money total = wallet.add(paycheck);
        System.out.println("Total after deposit: " + total); // $65.25 USD
    }
}
```

## 3. Practice Exercises

### Exercise 1: The `Book` Class (Encapsulation & Validation)
**Objective:** Create a well-encapsulated class with proper state protection.

**Requirements:**
1. Private fields: `title` (`String`), `author` (`String`), `pages` (`int`), `isBorrowed` (`boolean`).
2. Primary constructor setting `title`, `author`, and `pages`. Throw `IllegalArgumentException` if `pages <= 0`.
3. Provide getter methods for all fields.
4. Implement methods:
    - `borrowBook()`: Sets `isBorrowed` to `true`. Output warning if already borrowed.
    - `returnBook()`: Sets `isBorrowed` to `false`.

### Exercise 2: The `Time` Class (Constructor Overloading & Chaining)
**Objective:** Master constructor overloading using `this(...)` to reduce code duplication.

**Requirements:**
1. Private fields: `hours` (`int`, 0–23), `minutes` (`int`, 0–59), `seconds` (`int`, 0–59).
2. Implement 3 overloaded constructors:
    - `Time(int hours, int minutes, int seconds)` — Primary constructor with parameter validation.
    - `Time(int hours, int minutes)` — Defaults `seconds` to `0` via `this(hours, minutes, 0)`.
    - `Time(int hours)` — Defaults `minutes` and `seconds` to `0` via `this(hours, 0)`.
3. Implement `to12HourString()` returning formatted 12-hour strings (e.g., `"02:15:09 PM"`).
