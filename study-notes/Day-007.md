markdown_content = """# Day 9: Java OOP — Abstract Classes, Interfaces, & Default Methods

---

## 1. Core Concepts & Short Notes

### 1. Abstract Classes (`abstract`)
* **Definition**: An abstract class represents an **incomplete blueprint**. It cannot be instantiated directly using `new`.
* **State & Constructors**:
    * Abstract classes **can have fields** (instance variables, `static`, `final`, etc.).
    * Abstract classes **can have constructors**, which are invoked via `super()` when a subclass is instantiated.
* **Abstract Methods**:
    * Declared without a body (`abstract void process();`).
    * Non-abstract subclasses **must override** all inherited abstract methods.
* **When to use**: When classes share a **common identity/state** ("IS-A" relationship) and core code implementation, but require specialized behavior in specific methods.

---

### 2. Interfaces (`interface`)
* **Definition**: An interface defines a **contract** or capability that a class agrees to fulfill.
* **Fields & Methods**:
    * Fields are implicitly `public static final` (constants).
    * Methods are implicitly `public abstract` (unless marked `default`, `static`, or `private`).
* **Multiple Inheritance of Type**:
    * A class can `implements` multiple interfaces (e.g., `class PaymentService implements Authenticatable, RateLimited`).
* **When to use**: To define a role or capability ("CAN-DO" relationship) across unrelated class hierarchies.

---

### 3. Default & Static Methods in Interfaces (Java 8+)
* **Default Methods (`default`)**:
    * Allows interfaces to provide a default implementation body.
    * Preserves **backward compatibility**—new methods can be added to existing interfaces without breaking implementing classes.
* **Static Methods (`static`)**:
    * Utility/helper methods tied directly to the interface namespace (e.g., `AuditLogger.format()`). Cannot be overridden.
* **Diamond Problem Resolution**:
    * If a class implements two interfaces that contain identical default method signatures, the class **must explicitly override** the conflicting method.

---

## 2. Key Differences Matrix

| Feature | Abstract Class | Interface (Java 8+) |
| :--- | :--- | :--- |
| **Primary Focus** | Partial implementation / Shared Identity | Standard API Contract / Capabilities |
| **Multiple Inheritance** | Single inheritance (`extends Class`) | Multiple inheritance (`implements A, B, C`) |
| **State / Fields** | Can have instance variables & state | Only `public static final` constants |
| **Constructors** | Yes (called via subclass `super()`) | No constructors allowed |
| **Access Modifiers** | `public`, `protected`, `package-private` | Interface members are implicitly `public` |

---

## 3. Real-World Application Code: E-Commerce Notification Engine

Below is a production-style design for an enterprise notification system using an **Abstract Class** for shared dispatch state/logging and **Interfaces** with `default` methods for channel capabilities.
```java
import java.time.LocalDateTime;

// ==========================================
// 1. INTERFACES & DEFAULT METHODS
// ==========================================

/**
 * Contract for any channel that supports audit logging.
 */
interface AuditLoggable {
    // Default method providing fallback logging behavior
    default void logAudit(String recipient, String status) {
        System.out.printf("[%s] AUDIT LOG -> Sent to: %s | Status: %s%n",
                LocalDateTime.now(), recipient, status);
    }

    // Static interface utility method
    static String sanitizeRecipient(String recipient) {
        return recipient == null ? "UNKNOWN" : recipient.trim().toLowerCase();
    }
}

/**
 * Interface defining notification payload delivery.
 */
interface NotificationChannel extends AuditLoggable {
    void sendNotification(String recipient, String message);
    
    // Default method providing retry resilience
    default boolean sendWithRetry(String recipient, String message, int maxRetries) {
        int attempts = 0;
        while (attempts < maxRetries) {
            try {
                attempts++;
                sendNotification(recipient, message);
                logAudit(recipient, "SUCCESS (Attempt " + attempts + ")");
                return true;
            } catch (Exception e) {
                System.out.println("Attempt " + attempts + " failed: " + e.getMessage());
            }
        }
        logAudit(recipient, "FAILED after " + maxRetries + " attempts");
        return false;
    }
}

// ==========================================
// 2. ABSTRACT CLASS (Shared State & Identity)
// ==========================================

abstract class BaseNotificationProvider implements NotificationChannel {
    private final String providerName;
    private final boolean isProductionMode;

    public BaseNotificationProvider(String providerName, boolean isProductionMode) {
        this.providerName = providerName;
        this.isProductionMode = isProductionMode;
    }

    // Concrete method shared by all subclasses
    public void printHeader() {
        System.out.printf("--- Provider: %s [Mode: %s] ---%n", 
                providerName, isProductionMode ? "PROD" : "SANDBOX");
    }

    // Template method defining execution flow
    public final void dispatch(String recipient, String message) {
        printHeader();
        String cleanRecipient = AuditLoggable.sanitizeRecipient(recipient);
        sendWithRetry(cleanRecipient, message, 2);
    }

    public String getProviderName() {
        return providerName;
    }

    public boolean isProductionMode() {
        return isProductionMode;
    }
}

// ==========================================
// 3. CONCRETE IMPLEMENTATIONS
// ==========================================

class EmailNotificationProvider extends BaseNotificationProvider {
    private final String smtpHost;

    public EmailNotificationProvider(String providerName, boolean isProduction, String smtpHost) {
        super(providerName, isProduction);
        this.smtpHost = smtpHost;
    }

    @Override
    public void sendNotification(String recipient, String message) {
        if (!recipient.contains("@")) {
            throw new IllegalArgumentException("Invalid email address format.");
        }
        System.out.printf("Connecting to SMTP [%s]... Sending Email to %s: '%s'%n", 
                smtpHost, recipient, message);
    }
}

class SmsNotificationProvider extends BaseNotificationProvider {
    private final String apiKey;

    public SmsNotificationProvider(String providerName, boolean isProduction, String apiKey) {
        super(providerName, isProduction);
        this.apiKey = apiKey;
    }

    @Override
    public void sendNotification(String recipient, String message) {
        System.out.printf("SMS Gateway [API-KEY: %s...] Sending SMS to %s: '%s'%n", 
                apiKey.substring(0, 4), recipient, message);
    }
}

// ==========================================
// 4. DEMO RUNNER
// ==========================================

public class Day9Demo {
    public static void main(String[] args) {
        NotificationChannel emailChannel = new EmailNotificationProvider(
                "SendGrid", false, "smtp.sendgrid.net");
        
        BaseNotificationProvider smsChannel = new SmsNotificationProvider(
                "Twilio", true, "TWILIO_SECRET_KEY_9988");

        System.out.println("=== 1. Dispatching Email (With retry success) ===");
        emailChannel.sendNotification("ALICE@EXAMPLE.COM", "Your order #1001 has shipped!");

        System.out.println("\n=== 2. Dispatching SMS via Template Pipeline ===");
        smsChannel.dispatch(" +1-555-0192 ", "Your security code is: 482019");

        System.out.println("\n=== 3. Testing Failure & Retry Logic ===");
        emailChannel.sendWithRetry("invalid-email-address", "Test Retry Flow", 2);
    }
}
```

### Exercise 1: Multi-Channel Cloud Storage Exporter
Task:

Create an interface CloudStorageExporter with abstract method uploadFile(String fileName, byte[] data).

Add a default void uploadWithBackup(String fileName, byte[] data) method that calls uploadFile and logs a backup status message.

Implement concrete classes S3StorageExporter and GoogleCloudStorageExporter.
```java
interface CloudStorageExporter {
    void uploadFile(String fileName, byte[] data);

    default void uploadWithBackup(String fileName, byte[] data) {
        uploadFile(fileName, data);
        System.out.println("[Backup System] Successfully mirrored " + fileName + " to secondary backup storage.");
    }
}

class S3StorageExporter implements CloudStorageExporter {
    private final String bucketName;

    public S3StorageExporter(String bucketName) {
        this.bucketName = bucketName;
    }

    @Override
    public void uploadFile(String fileName, byte[] data) {
        System.out.println("Uploading " + data.length + " bytes to AWS S3 Bucket [" + bucketName + "] -> " + fileName);
    }
}

class GoogleCloudStorageExporter implements CloudStorageExporter {
    private final String projectId;

    public GoogleCloudStorageExporter(String projectId) {
        this.projectId = projectId;
    }

    @Override
    public void uploadFile(String fileName, byte[] data) {
        System.out.println("Uploading " + data.length + " bytes to Google Cloud Storage [Project: " + projectId + "] -> " + fileName);
    }
}
```

```java
public abstract class Payment {

    private String paymentId;
    private BigDecimal amount;

    public Payment(String paymentId, BigDecimal amount) {
        this.paymentId = paymentId;
        this.amount = amount;
    }

    public void process() {
        validate();
        makePayment();
        savePayment();
    }

    private void validate() {
        if (amount.compareTo(BigDecimal.ZERO) <= 0) {
            throw new IllegalArgumentException("Invalid amount");
        }
    }

    protected abstract void makePayment();

    private void savePayment() {
        System.out.println("Saving payment " + paymentId);
    }
}
public class CreditCardPayment extends Payment {

    public CreditCardPayment(String paymentId, BigDecimal amount) {
        super(paymentId, amount);
    }

    @Override
    protected void makePayment() {
        System.out.println("Processing credit card payment");
    }
}
public class PaypalPayment extends Payment {

    public PaypalPayment(String paymentId, BigDecimal amount) {
        super(paymentId, amount);
    }

    @Override
    protected void makePayment() {
        System.out.println("Processing PayPal payment");
    }
}
```
